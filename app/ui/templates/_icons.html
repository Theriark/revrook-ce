{#- The inline icon set (docs/design-system.md, Icons). Every icon is a 24-unit stroke drawing in the current text colour, hidden from assistive technology: the words next to it carry the meaning. Inline SVG needs no namespace in HTML; nothing is loaded from outside. An icon has one of four sizes, named so that every icon of a kind is the same size on every page (the stylesheet holds the values as --rv-icon-sm/md/lg/xl): sm 18px inside a button, a pill or a field (sign out, add, search, the switch) md 22px beside a line of text: navigation, list markers, source marks lg 36px the mark of a card: the import area, a small empty state, the drawer xl 48px the mark of an empty state that fills a page or a section -#} {% macro icon(name, size="md") -%} {%- set px = {"sm": 18, "md": 22, "lg": 36, "xl": 48}[size] -%} {%- endmacro %} {#- The mark of an evidence source: the icon of its family in a small tile beside the name of the source (the sources table, the integrations of the home empty state) -#} {% macro source_mark(code) -%} {{ icon(source_icon(code), "md") }} {%- endmacro %}
