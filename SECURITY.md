# Security policy

## Supported versions

revrook-ce is pre-release and has no supported versions yet.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately with GitHub private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Include the affected file or component, the steps to reproduce, and the impact you expect.

Do not include real client data, credentials or secrets in a report.

If the Report a vulnerability option is not shown, open a public issue that asks for a private contact route and contains no technical detail.
