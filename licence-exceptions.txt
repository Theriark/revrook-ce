#
# One line per package: name | SPDX expression | reason
#
# Use a line only when a package declares its licence ambiguously (for example
# the generic "BSD License" classifier) and you have read its LICENSE file. The
# line gives the identifier found in that file and says where it was read. The
# resolved expression must still be on the allow-list: an exception cannot admit
# a disallowed licence.
#
# Example:
# some-package | BSD-3-Clause | LICENSE file read at <url> on <date>
